# claw-kit-doc

This is the Cindy adapter's documentation entry. It selects documentation for
the current request and does not perform updates or configuration mutations.

- For updating claw-kit, read the **Cindy** section in
  `references/update.md` and guide the user through the documented plugin UI;
  Cindy intentionally has no claw-kit update skill.
- For project configuration, read `references/configuration.md`.
- For Truth or ADR structure, read `references/knowledge-format.md`.

Read only the relevant reference. Keep marketplace refresh, installed,
enabled, and running state as separate evidence.
